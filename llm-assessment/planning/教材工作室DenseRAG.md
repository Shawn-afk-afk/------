# 教材優先工作室與本機 Dense RAG

流程為「01 教材輸入 → 02 組成考卷 → 03 審題與匯出」，工作室預設開啟教材輸入。可貼原文或匯入文字PDF／DOCX／TXT／MD；掃描PDF須先提供文字層。載入既有ZJU第一、二章來源也會自動建立向量。

儲存教材只做解析與排隊，不在HTTP請求內跑長時間向量運算。背景worker自動切段與建立索引，顯示排隊、建置、可檢索與失敗。已有教材在升級時自動補建；失敗可按重建。封存教材不再參與新檢索，舊工作保留原文快照。

使用本機Ollama embeddinggemma（多語言文字向量），先以 ollama pull embeddinggemma 下載公開模型。沒有雲端推論、API金鑰、付費或自動安裝遠端程式。向量請求只連localhost，設定num_gpu=0在CPU建立向量，避免占用大模型的GPU。索引預設768維，實際維度從模型輸出驗證；模型digest改變時不能混用舊向量。

段落最多800字元，優先以段落或句末切分，重疊120字元；原文不改寫。保留material ID、原文字元起訖、PDF頁標記與SHA256。SQLite的rag_documents保存教材hash、模型、digest、維度、進度與錯誤；rag_chunks保存原文、位置與正規化float32向量。不需要另一個向量資料庫或額外port。

檢索採cosine similarity，僅搜尋所選教材。檢索預覽取前6段；出題預設12段，至少包含每個所選單元的一段。查詢向量使用問題前800字元；不是關鍵字排名，也沒有embedding失敗後的假向量或關鍵字fallback。相似度不是答案可信度，需要覆核。

出題每個大題都以出題偏好與大題名稱重新檢索，再交給原本的出題模型。原文段落、分數、位置、模型digest和唯一source_ref保留於exam_jobs工作快照；多個大題的引用不互相覆寫。審題頁提供「本次RAG檢索原文」，ZJU題目仍驗證引文回指選定第一／二章原文；一般科目保留各自範圍。Dense RAG不能保證題目正確，仍需教師核准。

可用ASSESSMENT_EMBED_MODEL設定另一個已安裝的本機embedding模型；變更後請重建。不能填cloud模型。大型教材首次建立索引需要時間，背景狀態完成後可試查。索引重建不覆寫教材原文，也不改動已分配題目與作答。
