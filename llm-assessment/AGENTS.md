# 知序 App 開發守則

本守則適用於 `llm-assessment/` 下的評量、教材、模型、寫作、登入與獨立頁面。

## 介面採用 Windows 98 與 98.css

- 每個 HTML 入口都先載入本機 `/vendor/98/98.css`，再載入功能樣式。對話框、子頁面和後續新增的工具延續同一套視覺。
- 優先使用 98.css 提供的 `window`、`title-bar`、`window-body`、`sunken-panel`、`status-bar` 和原生表單控制項。自訂 CSS 用於版面、編輯器及狀態的必要調整。延續方正邊框、灰色視窗、浮雕控制項、內凹輸入區、藍色標題列與青色桌面。
- 維持本機可用。介面依賴與字型放在現有靜態資源中。保留鍵盤操作、焦點提示、表單標籤及窄螢幕可讀性。
- 修改前端後，檢查主要頁面、表單、空白狀態與對話框是否仍由 98.css 呈現。角色介面同時檢查教師與學生帳號。

## 教師與學生的寫作區

- 教師端顯示出題與分配介面，可設定題型、教材範圍、目標字數、代擬上限以及個別或共同作答。學生端顯示受邀題目、教材片段、編輯器、討論和助教，並可建立個人自由稿。
- 教師以知序管理者角色識別。教材庫與寫作題目設定需要伺服器驗證角色。教師附上的原文片段保存於作品，只有房間成員可讀。
