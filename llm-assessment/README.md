# 知序 · LLM 理解與實作評量

獨立運作的教材評量網站，採用本機 SQLite、Ollama 與 WSL2。介面使用本機提供的 98.css。未來整合其他專案時，可沿用 HTTP API 與題庫 JSON 匯入／匯出。

## 啟動

在此資料夾開啟 PowerShell：

```powershell
.\scripts\Prepare-Runner.ps1
.\scripts\Prepare-Model.ps1
.\scripts\Start-App.ps1
```

開啟 http://127.0.0.1:8765，親自建立第一位管理者。沒有預設正式帳密。後台「設定」預設使用 `gemma4:12b-mxfp8`。需要先啟動 Ollama 本機服務；下載模型不等於已驗證推論。

## 創意寫作 IDE

啟動知序後，教師從側欄切到「寫作出題」，學生切到「創意寫作 IDE」。兩者沿用同一個知序工作區，`/writing` 也可依登入角色直接開啟該區。寫作共編使用 Python 3.11 以上。請先把下列依賴安裝到啟動知序所使用的同一個 Python 環境。

```sh
python -m pip install -r llm-assessment/requirements-writing.txt
```

教師可建立主題式、段落或自由寫作題目，設定字數和教材範圍，再選擇發給哪些學生。個別作答會為每位學生建立一份獨立草稿，共同寫作則使用同一份草稿。學生可以寫受邀作品，也可以建立自己的自由稿。受邀學生只會看到附在作品上的教材片段。編輯器支援篇章、同步游標、段落引用、版本儲存與還原，以及 Markdown 匯出。Markdown 標題會列在篇章大綱。

主題式與段落寫作可用「AI 引導式出題」輸入提示詞，套用並編輯模型產生的寫作情境、任務、引導步驟與自我檢查，再分配給學生。學生可在編輯器按「繳交作業」，教師從該題的「查看作業批改」閱稿、給分和發布回饋。AI 批改只填入建議，由教師確認發布。教師也可開放修訂，讓學生重新繳交。

行內續寫可以在編輯器開啟自動提示，也可以按「提示幾個字」按需取得。討論室用 `@助教` 呼叫助教。管理者可在「模型轉接槽」為寫作助教選擇本機來源。寫作槽未指定時沿用出題槽，討論室助教需要背景工作。使用 `--no-worker` 啟動時，討論室的助教工作不會執行。詳見[寫作助教介入規則書](planning/寫作助教介入規則書.md)。

編輯器的瀏覽器套件已包在本機靜態資源內。要更新套件時，在 `llm-assessment/writing-client` 執行 `npm ci` 和 `npm run build`。

## 本機測試帳號與忘記密碼

使用回環位址啟動服務並設定 `ASSESSMENT_LOCAL_DEMO=1`、`ASSESSMENT_DEMO_TEACHER_PASSWORD` 和 `ASSESSMENT_DEMO_STUDENT_PASSWORD` 時，已登記的 `teacher` 和 `student` 測試帳號可在登入頁按「忘記密碼」。輸入測試帳號後，系統會恢復主機環境設定的測試密碼並填入表單。

## 使用順序

1. 在「題庫與覆核」檢查草稿、詳解、閱讀位置、原始論文與分項規準，確認後核准。
2. 建立組員帳戶；每人只會看到自己的評量及已發布報告。
3. 建立評量，選題、配分、指定組員與截止時間，決定是否允許練習及自動發布。
4. 作答提交後，後端依序執行批改工作；人工可調整分項、註記及發布。原始 AI 結果與調整紀錄保留。重新開放作答會產生新的作答版本。
5. 查看能力分項與改善建議。分析區分練習／正式評量及題型、難度與支援条件，不把作答紀錄直接解讀成學習動機。

## 題庫與詳解

目前原始題庫共 61 題，涵蓋第一章 1.1–1.5、第二章 2.1–2.6。最新版本為 31 題英文、30 題中文，15 題提供不需執行的程式閱讀材料；另外保留 5 題 Python 實作與 8 題研究／教學案例延伸。英文題允許中英文解釋，詳解仍以中文為主。已取消獨立手算題型，著重資料流、狀態、標籤、可見範圍與公平評測。案例不是組員自己的實驗。

2026-10-13 的語言與邏輯修訂建立 41 個新草稿版本，不覆寫原題或已分配快照。請先覆核並核准新版，再加入新評量；題庫可依語言篩選。`backend/revise_bank.py` 可重複執行，不重複建立版本，也不改動使用者後續編輯的版本。

新增選擇與互動題預設各 12 分：後端核對選项／操作結果占 6 分，AI 評分理由占 6 分。複選的操作分需全對，漏選、多選或重複選項不得操作分；人工仍可依分項規準調整。正解只存於私有答案欄位，不傳給組員。

每題管理者詳解包含參考答案、解題步驟、常見錯誤、實務用途與教材章節／頁碼／搜尋關鍵字。實作提供參考程式，可在後台執行公開與隱藏測試。公開論文延伸題會標明來源與可接受的替代方案；參考答案是原創教學說明，仍需人工覆核。組員介面不提供詳解、私有規準或隱藏測試答案。

題目版本、教材來源文件、作答、評分及人工紀錄儲存在 `backend/assessment.sqlite3`。題目修改產生新版本，已分配評量保留當時核准內容。

## 批改與程式執行

客觀互動以規則核對；Python 由主機 WSL2 重新執行公開及隱藏測試；其他分項由本機 AI 依核准規準給 0–3 等級、引用作答證據與回饋，再換算指定配分。無效 JSON、證據不符或模型失敗會保留待批改，不產生假的完成分數。實作預設需要人工覆核後發布。

WSL2 Ubuntu 使用 bubblewrap 與 prlimit：隔離網路、限制 CPU／記憶體／輸出及程序數。學生程式不會取得隱藏測試的預期答案。沒有 Docker 或 GPU 需求。學生瀏覽器的 Pyodide 只供公開測試練習，第一次載入需要網路；正式分數不信任瀏覽器傳回的結果。此題庫程式以 Python 標準函式庫為主。

## ngrok

先建立本機管理者，再安裝 [ngrok 官方 Windows 版本](https://ngrok.com/download/windows)，依官方說明設定自己的免費帳戶。腳本讀取既有設定，請勿把 token 放入原始碼。

```powershell
.\scripts\Start-Tunnel.ps1 -NgrokPath 'C:\工具\ngrok.exe'
```

此腳本重新啟動網站為 HTTPS cookie 模式，再建立通道。網址可在本機 http://127.0.0.1:4040/api/tunnels 查看。免費方案有額度限制，請從自己的 ngrok 儀表板確認。主機需保持開機；Ollama 不對外開放。

```powershell
.\scripts\Backup-Database.ps1
.\scripts\Stop-App.ps1
```

備份包含完整資料庫。停止腳本只停止本網站與其通道，不停止共用 Ollama 或 WSL2。

```powershell

python -m unittest discover -s tests -p 'test_*.py' -v
```

## 教材優先與自動 Dense RAG

工作室依序為教材輸入、組成考卷、審題匯出。儲存教材會自動建立本機EmbeddingGemma向量索引；可預覽原文、頁碼與向量相似度，出題檢索原文保留於工作快照。[操作與實作說明](planning/教材工作室DenseRAG.md)。先下載`ollama pull embeddinggemma`，再啟動網站；沒有向量資料庫額外port或雲端推論。

## 個人技能適性批改第一版

教師從「題庫與覆核 → 建立修改版本 → 轉為布林指標草稿」建立 `max_level: 1` 的規準。請逐項核對行為、達成描述與配分，必要時拆分指標。分項可指定 `skill_id`，預設沿用題目技能。新版本核准後才用於新的評量。既有 0–3 級規準仍依其配分計算。

「查看／調分」提供布林達成選項與個人技能紀錄。教師選擇本次無提示個人作答、有支援或尚未確認，發布後更新追蹤與推薦。學生從既有報告頁查看技能狀態與證據。建議題的「前往組卷」會帶入題目及對應學生，教師檢查配分後發布下一份評量。

第一版採 RULE_ONLY。兩道不同題連續獨立成功為本輪驗證通過，兩次連續獨立失敗為待補強，單次失敗待確認，支援後成功待驗證。這是可修改的試行政策，尚待課堂驗證。活動仍沿用整份交卷與教師發布流程。BKT／PFA 使用程式中具版本的示範參數，教師可展開查看未校準估計，正式推薦使用規則。現階段尚無參數訓練入口或逐題自動適性施測。

技能資料由每次作答輪次最新已發布報告按作答順序重播。同題以題目識別碼去重，重開作答、提示、協作與缺少證據的紀錄保留排除原因。改判後重新發布即重算，重試不累加觀測。只有已發布結果進入學生報告及推薦。新版發布會替換本模組及舊技能篩選器的待審建議，保留其他已決定的建議。

回歸檢查使用 `python -m unittest discover -s tests -p test_adaptive.py` 及既有 `test_workflow.py`。測試資料庫與正式紀錄隔離。

## 教材自主練習

教師在「教材出題工作室」的教材列表點選「開放自主練習」，學生即可從工作區的「自主練習」選該教材、填寫選用主題並生成 3 或 5 道單選題。出題使用「模型轉接槽」的教材出題模型，請選用已安裝的本機模型。

交卷後，學生可在自己的練習紀錄查看得分、正解、解析及教材引文。停止分享或封存教材後，相關練習暫停開放。自主練習的成績保存在個人練習紀錄，正式評量與技能追蹤仍採已發布的教師評分證據。

## AI 教學平台教材包

1. 在來源平台選擇已發布的教材版本，從「教材列印與 JSON 輸出」按「下載教材 JSON」。
2. 在知序開啟「教材出題工作室 → 教材輸入 → 匯入 AI 教學平台教材包」，選擇 JSON，按「預覽學生版」。支援教材包版本 1、內容結構 2.0.0 與 3.0.0，檔案上限 5 MiB。
3. 核對內容並選擇國文、英語、歷史、地理或公民，再按「存入教材庫」。同一資源版本在同科只會存一份。匯入後沿用既有 RAG 排程，也可用於該科組卷。LLM 科仍使用知序的 ZJU 第一、二章來源。
4. 教師在教材列按「開放自主練習」後，學生可在「自主練習」選該教材，按「閱讀教材」或生成新練習。停止開放或封存會停止學生存取。

匯入使用學生可見的區塊與題目順序。字彙、概念關係、題幹與選項轉為教材文字。教師備註、答案、規準、提示與來源原文快照均略過。來源題目可供閱讀與備課，以知序組卷時會由現有出題流程生成新題。作品上傳題的說明可讀，檔案繳交功能仍需另行串接。
